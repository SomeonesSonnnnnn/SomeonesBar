## What is it?

SomeonesBar replaces the Windows taskbar with a modern glass dock in the style of macOS. It adds a notch with time, weather and quick settings, a bubble app launcher, desktop widgets, and live animated wallpapers. Everything is native (C# and WPF), so it stays light on your computer.

## Features

| | |
|---|---|
| **Glass dock** | Real-time glass, smooth icon magnification, launch bounce, badges for notifications, and a choice of icon styles (original, glass, dark, light, mono) |
| **Notch** | Time, weather, notifications, clipboard history and quick settings in one place |
| **Bubble launcher** | Replaces the Start menu. Drag your apps into your own order and search by typing |
| **Widgets** | A desktop clock and a music widget that shows what is playing, with synced lyrics |
| **Live wallpapers** | 12 animated scenes, from a quiet forest to a synthwave sunset |
| **Light on resources** | Wallpapers, widgets and glass pause themselves while another window covers them |
| **Updates** | New versions download in the background, and a changelog shows after each update |

## Live wallpapers

Forest, Beach, City, Space, Aurora, Flow, Synthwave, Warp, Ocean, Night rain, Code rain and Galaxy. The Aurora and Galaxy scenes have shooting stars, and the Galaxy has sparkling stars.

## Music widget

Six layouts to choose from: **Card**, **Vinyl**, **Mini**, **Poster**, **Lyrics** and **Spectrum**. You can change the size, accent colour, bar style, corner roundness, opacity and lyric size. It appears while something is playing and hides when it stops.

## Install

| Step | What to do |
|---|---|
| **1** | Download **SomeonesBar-win-Setup.exe** from the [latest release](https://github.com/SomeonesSonnnnnn/SomeonesBar/releases/latest) |
| **2** | Run it. Nothing else needs to be installed, and no administrator rights are needed |
| **3** | If Windows shows "Windows protected your PC", click **More info**, then **Run anyway** (the app is not code-signed yet) |
| **4** | A short welcome helps you pick a look, a wallpaper and your widgets |

To remove it, open Windows Settings, then Apps, find SomeonesBar and choose Uninstall.

## Updates

SomeonesBar checks this page for new releases. When one is ready, the notch shows **Update ready**. Click it to restart into the new version. You can also press **Check now** in Settings, then General.

## Requirements

Windows 10 (version 2004 or newer) or Windows 11, 64-bit. Nothing else: the .NET runtime is included in the installer.
